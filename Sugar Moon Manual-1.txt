Manual del Usuario de Sugar Moon
 
Introducción:
 
Sugar Moon es un lenguaje de programación mágico orientado a objetos diseñado para la manipulación de la realidad.  Este manual proporciona una guía completa para principiantes y usuarios avanzados.
 
I. Conceptos Básicos:
 
- Tipos de Datos: Sugar Moon soporta los siguientes tipos de datos:
-  int : Enteros (ej: 10, -5, 0).
-  float : Números de punto flotante (ej: 3.14, -2.5).
-  string : Cadenas de texto (ej: "Hola mundo", "Sugar Moon").
-  bool : Booleanos (verdadero/falso,  true / false ).
-  object : Objetos con propiedades y métodos (ver sección III).
- Variables: Las variables se declaran usando el nombre de la variable seguido de dos puntos y el tipo de dato.  Ejemplo:
mana: int = 100;
nombreJugador: string = "Aventurero";
 
- Operadores: Sugar Moon utiliza operadores aritméticos (+, -, *, /, %), de comparación (==, !=, >, <, >=, <=), lógicos (&&, ||, !), y de asignación (=).
- Comentarios: Los comentarios se indican con  //  para comentarios de una sola línea y  /* ... */  para comentarios de varias líneas.
 
II. Estructuras de Control:
 
- Condicional  if-else :
if (mana > 50) {
  // ... código ...
} else {
  // ... código ...
}
 
- Bucles  while :
while (enemigo.isAlive()) {
  // ... código ...
}
 
- Bucles  for :
for (i: int = 0; i < 10; i++) {
  // ... código ...
}
 
 
III. Programación Orientada a Objetos:
 
- Clases: Las clases se definen usando la palabra clave  class .  Ejemplo:
class Enemigo {
  constructor(nombre: string, salud: int) {
    this.nombre = nombre;
    this.salud = salud;
  }
  nombre: string;
  salud: int;
  estaVivo(): bool { return this.salud > 0; }
}
 
- Objetos: Los objetos son instancias de una clase.  Ejemplo:
enemigo1: Enemigo = new Enemigo("Goblin", 50);
 
- Métodos: Los métodos son funciones dentro de una clase.  Ejemplo:   estaVivo()  en la clase  Enemigo .
- Propiedades: Las propiedades son variables dentro de una clase.  Ejemplo:  nombre  y  salud  en la clase  Enemigo .
 
IV. Hechizos (Funciones Mágicas):
 
Los hechizos son funciones especiales que manipulan la realidad.  Se definen usando la palabra clave  spell .  Ejemplo:
 
spell teleportar(destino: string, probabilidad: float = 0.9) {
  if (random(0,1) < probabilidad) {
    ubicacion = destino;
  } else {
    print("Teletransportación fallida!");
  }
}
 
 
V. Manejo de Probabilidades y Efectos Secundarios:
 
Muchos hechizos tienen una probabilidad de éxito y efectos secundarios.  Se utilizan funciones como  random(0,1)  para generar números aleatorios entre 0 y 1, y se manejan los efectos secundarios con sentencias  if-else  o bloques de código específicos.
 
VI. Funciones Integradas:
 
Sugar Moon proporciona varias funciones integradas, incluyendo:
 
-  print(mensaje: string) : Imprime un mensaje en la consola.
-  random(min: int, max: int) : Genera un número aleatorio entre  min  y  max .
-  time() : Devuelve la marca de tiempo actual.
-  wait(tiempo: int) : Pausa la ejecución durante un tiempo determinado.

Para simplificar, asumimos que Starlight Sugar Moon se ejecuta a través de un entorno de línea de comandos o terminal.  No se requiere la instalación de un IDE complejo.

2. Instalación:  Ejecuta el archivo descargado y sigue las instrucciones en pantalla.  El intérprete se instalará en una ubicación predeterminada o te permitirá elegir una ubicación personalizada.
3. Configuración de la variable de entorno (opcional):  Para facilitar la ejecución de comandos desde cualquier directorio, agrega la ruta de instalación del intérprete a la variable de entorno  PATH .
 
III.  Ejecución de código:
 
Una vez instalado el intérprete, puedes ejecutar código Starlight Sugar Moon de dos maneras:
 
1. Ejecución directa desde la línea de comandos:Abre tu terminal o línea de comandos, navega hasta el directorio donde se encuentra tu archivo de código (ej:  mi_programa.ssm ) y ejecuta el comando:
ssm mi_programa.ssm
 
2. Ejecución interactiva (modo REPL):Algunos intérpretes permiten la ejecución interactiva.  Ejecuta el intérprete sin argumentos:
ssm
 
 
Esto abrirá un entorno interactivo donde puedes escribir y ejecutar código Starlight Sugar Moon línea por línea.

experience("pesadillaBosque") {

  }

  // Aparición de criaturas
  creature("araña_gigante", model: "araña.obj", animation: "arrastrándose", position: {x: 100, y: 50});
  creature("sombra_amenazante", model: "sombra.obj", animation: "acercándose", position: {x: -150, y: 100});

  onProximity("araña_gigante", distance: 20) {

Sugar Moon: Sintaxis y Semántica
 
Este apartado define la sintaxis y la semántica del lenguaje de descripción de escenas Sugar Moon.  Su objetivo es generar descripciones detalladas para motores gráficos y sistemas de IA, permitiendo la creación de mundos virtuales y experiencias interactivas mediante comandos semánticos.
 
I. Sintaxis Básica:
 
Sugar Moon utiliza una sintaxis declarativa basada en funciones y parámetros.  Cada función representa una acción o una propiedad del mundo virtual.  La sintaxis general es la siguiente:
 
 función(parámetro1: valor1, parámetro2: valor2, ...) 
 
Donde:
 
- función:  Es el nombre de la función (ej:  environment ,  createObject ,  spell ).  Las funciones son mayúsculas y en singular, se encuentran definidas en la sección de funciones integradas.
- parámetro:  Es el nombre de un parámetro de la función (ej:  time ,  lighting ,  model ). Se utiliza  CamelCase  para parámetros. Los parámetros son sensibles a mayúsculas y minúsculas.
- valor:  Es el valor asignado a un parámetro.  Los valores pueden ser cadenas de texto (entre comillas), números, booleanos ( true ,  false ), o estructuras de datos anidadas. Los tipos de datos se infieren del contexto.
 
II. Semántica:
 
La semántica de Sugar Moon se basa en la interpretación contextual de las funciones y sus parámetros.  Cada función tiene un significado específico y los parámetros modifican su comportamiento.
 
A. Funciones principales:
 
-  environment(ambiente: string, time: string, lighting: string, sounds: array<string>, ...) : Define las características generales del entorno.  Los parámetros incluyen  ambiente  (ej: "bosque", "ciudad"),  time  (ej: "día", "noche"),  lighting  (ej: "soleado", "oscuro"),  sounds  (una lista de sonidos ambientales), entre otros.
-  createObject(nombre: string, model: string, properties: object) : Crea un objeto en la escena.  Los parámetros incluyen  nombre  (un identificador único para el objeto),  model  (el nombre del archivo de modelo 3D), y  properties  (un objeto JSON que define las propiedades del objeto, ej:  {color: "rojo", tamaño: 10} ).
-  character(nombre: string, model: string, actions: array<string>, properties: object) : Define un personaje en la escena. Similar a  createObject , con la adición de  actions  (una lista de acciones del personaje).
-  spell(nombre: string, sequence: array<function>) : Define un hechizo o evento mágico.  sequence  es una lista de funciones a ejecutar secuencialmente.
-  sensoryExperience(subject: string, feeling: string, intensity: number) : Describe las sensaciones subjetivas de un personaje o observador.
 
B.  Manejo de estructuras de datos:
 
- Los arrays se definen con corchetes  [] .
- Los objetos (JSON) se definen con llaves  {} .
- Los valores se asignan con dos puntos  : .
 
III. Ejemplos:
 
environment(ambiente: "ciudad", time: "noche", lighting: "lluvia", sounds: ["tráfico", "truenos"])
createObject(coche: "coche1", model: "coche_rojo.obj", properties: {velocidad: 80, color: "rojo"})
character(personaje: "Sarah", model: "sarah.obj", actions: ["correr", "mirar_atras"], properties: {miedo: alto})
spell(teletransportacion, sequence: [abrirPortal(), moverPersonaje(personaje: "Sarah", destino: "otra_ciudad"), cerrarPortal()])
 
 
IV.  Funciones Integradas (Ejemplo parcial):
 
(Una lista completa de las funciones integradas se proporcionará en una sección separada del manual).
 
-  abrirPortal() : Abre un portal.
-  moverPersonaje(personaje: string, destino: string) : Mueve un personaje a una ubicación especificada.
-  cerrarPortal() : Cierra un portal.
-  sonidoAmbiente(nombre: string, intensidad: number) : Añade un sonido ambiental a la escena.
 
Esta definición proporciona una estructura más rigurosa a Sugar Moon, aunque se mantiene como un lenguaje declarativo.  La interpretación de los parámetros sigue dependiendo del motor gráfico o el sistema de IA que lo utilice.



Sugar Moon:  Elementos Avanzados y Control de Flujo
 
Esta sección extiende la definición de Sugar Moon, añadiendo estructuras de control de flujo, manejo de variables, y mecanismos para un manejo más robusto de errores.  Estas características son necesarias para convertir Sugar Moon en un lenguaje de programación más completo y potente.
 
I.  Tipos de Datos:
 
Sugar Moon soporta los siguientes tipos de datos:
 
- String: Cadenas de texto entre comillas ( "texto" ).
- Number: Números (enteros o decimales).
- Boolean: Valores booleanos ( true ,  false ).
- Object: Objetos JSON con pares clave-valor ( {clave1: valor1, clave2: valor2} ).
- Array:  Listas ordenadas de valores, entre corchetes ( [valor1, valor2, valor3] ).
 
II. Variables:
 
Las variables se declaran usando la palabra clave  var  seguida del nombre de la variable y su tipo de datos (opcional, se infiere si no se especifica).  La asignación se realiza con el operador  = .
 
var nombre: String = "Aventura";
var velocidad: Number = 100;
var activo: Boolean = true;
 
 
III.  Estructuras de Control de Flujo:
 
- if-else: Permite ejecutar bloques de código condicionalmente.
 
if (velocidad > 50) {
  imprimir("Velocidad alta!");
} else {
  imprimir("Velocidad baja.");
}
 
 
- for:  Iteración sobre un array.
 
var listaNumeros: Array<Number> = [1, 2, 3, 4, 5];
for (var i: Number = 0; i < listaNumeros.length; i++) {
  imprimir(listaNumeros[i]);
}
 
 
- while:  Iteración mientras una condición sea verdadera.
 
var contador: Number = 0;
while (contador < 10) {
  imprimir(contador);
  contador = contador + 1;
}
 
 
IV. Manejo de Errores:
 
Sugar Moon utiliza la función  try-catch  para manejar errores.
 
try {
  // Código que puede generar un error
  var resultado: Number = 10 / 0;
} catch (error: String) {
  imprimir("Error: " + error);
}
 
 
V.  Funciones Extendidas:
 
Se añaden nuevas funciones para un control más preciso sobre la generación de contenido:
 
-  setColor(objeto: String, color: String) : Cambia el color de un objeto.
-  setOpacity(objeto: String, opacidad: Number) : Establece la opacidad de un objeto (0.0 a 1.0).
-  setPosition(objeto: String, x: Number, y: Number, z: Number) : Establece la posición de un objeto en coordenadas 3D.
-  addEffect(objeto: String, efecto: String) : Añade un efecto visual a un objeto (ej: "fuego", "niebla").
-  playSound(sonido: String, intensidad: Number, posicion: Object) : Reproduce un sonido con parámetros de intensidad y posición.
-  stopSound(sonido: String) : Detiene un sonido.
 
VI.  Ejemplo Completo:
 
var personajePrincipal: String = "héroe";
var enemigo: String = "villano";
var saludPersonaje: Number = 100;

createObject(personajePrincipal, model: "heroe.obj", properties: {arma: "espada"});
createObject(enemigo, model: "villano.obj", properties: {arma: "hacha"});

while (saludPersonaje > 0) {
  atacar(personajePrincipal, enemigo, daño: 20);
  if (saludPersonaje <= 0) {
      imprimir("El héroe ha muerto!");
      break;
  }
  atacar(enemigo, personajePrincipal, daño: 10);
  if(getHealth(enemigo) <= 0){
      imprimir("El villano ha muerto!");
      break;
  }
}


function atacar(atacante: String, defensor: String, daño: Number){

Sugar Moon:  Manejo Inteligente de Errores
 
Sugar Moon se basa en un sistema de corrección y completamiento inteligente de errores impulsado por IA.  En lugar de detener la ejecución ante un error, la IA intenta resolverlo o completar la instrucción incompleta. Esto se aplica tanto a errores de sintaxis como a errores semánticos.
 
I.  Tipos de Intervención de la IA:
 
La IA puede intervenir de las siguientes maneras:
 
- Corrección de sintaxis:  Si se detecta un error de sintaxis (ej: un parámetro faltante, un tipo de dato incorrecto), la IA intenta corregir el código basándose en el contexto y la intención del usuario.  Se mostrará un mensaje indicando la corrección realizada.
- Completamiento semántico: Si una instrucción está incompleta o ambigua, la IA intenta completarla basándose en el contexto y en las mejores prácticas.  Se mostrará un mensaje indicando la completación realizada.
- Sugerencias de corrección:  En algunos casos, la IA puede no ser capaz de corregir el error automáticamente, pero ofrecerá sugerencias al usuario para corregirlo manualmente.
- Generación de código alternativo: En situaciones complejas, la IA puede generar una versión alternativa del código que produce el resultado deseado, explicando los cambios realizados.
 
II.  Mensajes de la IA:
 
Los mensajes de la IA se mostrarán al usuario para informar sobre las intervenciones realizadas.  Estos mensajes contendrán:
 
- El tipo de error detectado.
- El código original que generó el error.
- El código corregido o completado.
- Una breve explicación de la corrección o completación realizada.
 
III.  Ejemplos:
 
- Error de sintaxis:Código original:  createObject(modelo: "casa.obj")  (Falta el nombre del objeto)
Mensaje de la IA:   Error de sintaxis detectado: Parámetro 'nombre' faltante en 'createObject'. Se ha añadido automáticamente 'casa1'. Código corregido: createObject(nombre: "casa1", modelo: "casa.obj") 
- Completamiento semántico:Código original:  environment(ambiente: "bosque")  (Falta información sobre iluminación y tiempo)
Mensaje de la IA:   Instrucción incompleta: Se ha completado la instrucción 'environment' con valores predeterminados para 'time' y 'lighting'. Código completado: environment(ambiente: "bosque", time: "día", lighting: "soleado") 
- Sugerencia de corrección:Código original:  moverPersonaje(personaje: "inexistente", destino: "casa")  (Personaje no definido)
Mensaje de la IA:   Advertencia: El personaje 'inexistente' no está definido.  Por favor, verifique el nombre del personaje o cree un nuevo personaje. 
 
IV.  Limitaciones:
 
Aunque la IA se esfuerza por corregir y completar el código, existen situaciones donde la corrección automática puede no ser posible o puede producir resultados inesperados.  Es fundamental para el usuario revisar el código generado por la IA para asegurar que se ajusta a sus intenciones.

La IA se convierte en una parte integral del proceso de desarrollo, no solo como herramienta para detectar errores, sino también para solucionarlos.  Sin embargo, se enfatiza la importancia de la supervisión humana para garantizar la exactitud y la intención del código.

Sugar Moon:  Entrada de Lenguaje Natural
 
Sugar Moon permite a los usuarios describir escenas y acciones usando lenguaje natural, en lugar de código formal.  Un potente motor de procesamiento de lenguaje natural (PNL) analiza la entrada del usuario y la traduce automáticamente a código Sugar Moon válido y ejecutable.
 
I.  Funcionamiento:
 
El proceso de entrada de lenguaje natural consta de los siguientes pasos:
 
1. Entrada del usuario: El usuario introduce una descripción textual de la escena o acción deseada utilizando lenguaje natural.  La descripción puede ser tan detallada o tan concisa como el usuario desee.
2. Análisis de PNL: El motor de PNL analiza la entrada del usuario, identificando entidades, acciones, relaciones y otros elementos clave.
3. Traducción a código Sugar Moon:  Basándose en el análisis del PNL, el motor genera código Sugar Moon equivalente, optimizado para claridad y eficiencia.
4. Validación y corrección: El código generado se valida para asegurar que es sintácticamente correcto y semánticamente consistente.  La IA corrige automáticamente cualquier error o ambigüedad.
5. Ejecución: El código Sugar Moon validado se ejecuta, generando la salida deseada (gráficos, descripción textual, etc.).
 
II.  Ejemplos:
 
- Entrada: "Un bosque oscuro y misterioso, con árboles altos y niebla densa.  El viento susurra entre las hojas."
- Salida (código Sugar Moon):
 
environment(ambiente: "bosque", time: "noche", lighting: "oscuro", niebla: true, sonidos: ["viento"])
 
- Entrada: "Un robot gigante rojo ataca a un héroe con una espada. El héroe bloquea el ataque."
- Salida (código Sugar Moon):
 
createObject(robot, model: "robot_rojo.obj", propiedades: {tamaño: "gigante"});
createObject(heroe, model: "heroe.obj", propiedades: {arma: "espada"});
character(heroe, acciones: ["bloquear"]);
character(robot, acciones: ["atacar"]);

atacar(robot, heroe);
bloquearAtaque(heroe, robot);
 
- Entrada:  "El cielo se ilumina con un destello brillante."
- Salida (código Sugar Moon):
 
addEffect(cielo, efecto: "destello", intensidad: 1.0, duracion: 0.5);
 
 
III.  Consideraciones:
 
- La exactitud de la traducción depende de la claridad y precisión de la entrada del usuario.  Descripciones ambiguas o poco claras pueden resultar en código inesperado.
- El motor de PNL está en constante aprendizaje y mejora.  Con el tiempo, su capacidad para comprender y traducir lenguaje natural se volverá más sofisticada y precisa.
- Para obtener los mejores resultados, utilice un lenguaje claro, preciso y conciso en sus descripciones.
